# 手机端设置清单（各主流品牌）

USB 共享网络的稳定性，**一大半取决于手机侧这几项设置**，而不是电脑。
本表把各品牌对应的菜单路径集中列出，照着关掉/打开即可。

> ⚠️ 菜单名称与层级会随系统版本、地区版本、运营商定制版变化。本表按各系统的主流版本整理，
> 若你的机器上找不到，请用「设置」顶部的**搜索框**搜下表中的关键词——这比记路径可靠得多。

---

## 只做三件事，收益已经占八成

| 优先级 | 要做的操作 | 为什么 |
|---|---|---|
| ★★★ | 关掉「**智能切换上网卡 / 自动切换数据卡**」 | 手机信号一抖动就偷偷切到另一张卡，切换瞬间必断流；单卡用户也可能因它反复重选网络 |
| ★★★ | 关掉「**WLAN 助理 / 智能网络切换 / WLAN+**」 | 它会在 WLAN 与移动数据之间自动来回切，正好把 USB 共享也牵连进去 |
| ★★☆ | 打开「**休眠时保持网络连接**」 | 锁屏后省电策略会掐掉数据连接，表现为「放着不动就断」 |

## 通用速查：同一个功能的不同叫法

| 功能 | 各品牌常见叫法 |
|---|---|
| 自动切换数据卡 | 智能切换上网卡 · 自动切换数据卡 · 智能双卡切换 · 数据卡切换 · 通话时智能切换上网卡 · 自动切换到更好的网络 |
| WLAN 与移动数据互备 | WLAN+ · WLAN 助理 · 智能网络切换 · 网络助理 · 自动切换网络 · Smart network switch · 自动切换移动数据 |
| 休眠保持连接 | 休眠时始终保持网络连接 · 始终连接 · 休眠时保持 WLAN 连接 · 睡眠期间保持 WLAN 开启 · 保持数据连接始终开启 |
| USB 共享开关 | USB 共享网络 · USB 网络共享 · USB tethering（通常在「个人热点」的「更多共享设置」里） |

**找不到时最快的三条路：**
1. 设置里搜关键词：`共享`、`热点`、`智能切换`、`WLAN 助理`、`休眠`
2. 开发者选项 → 关掉「**USB 调试**」（能顺带消除 `HDB Interface` 之类的报错接口，见下）
3. 拨号盘输入 `*#*#4636#*#*` → 工程菜单里锁网络制式

## 华为 / 荣耀（HarmonyOS / MagicOS）

| 项 | 路径 |
|---|---|
| USB 共享 | 设置 → 移动网络 → 个人热点 → 更多共享设置 → USB 共享网络 |
| 关智能切换 | 设置 → 移动网络 → SIM 卡管理 → 智能切换上网卡 → 关 |
| 关 WLAN+ | 设置 → WLAN → 更多设置 → WLAN+ → 关 |
| 休眠保持 | 设置 → 电池 → 更多电池设置 → 休眠时始终保持网络连接 → 开 |
| 锁 4G | 拨号盘 `*#*#4636#*#*` → 手机信息 → 设置首选网络类型 → LTE only |
| 开发者选项 | 设置 → 系统和更新 → 开发人员选项 |

> 华为/荣耀机型开启「USB 调试」后会多出一个 `HDB Interface`。没装官方驱动时它常年处于 **Error** 状态，
> Windows 会周期性重试枚举，**表现为共享网络无规律瞬断**。关掉 USB 调试、或直接禁用该接口都能解决
> （`tether-doctor.ps1 -Apply` 会自动做后者）。

## 与「同时开 Wi-Fi 热点」有关

手机同时做 USB 共享和 Wi-Fi 热点时，两者**走的是同一条蜂窝链路**：

- 热点设备吃掉的带宽，就是从你电脑这里扣掉的（手机内部没有 QoS，先到先得）；
- 热点建议用 **5GHz**（空口时间短、干扰小）；
- 热点上那台设备请关掉**自动更新 / 云同步 / 后台备份**；
- 手机同时「收基站 + 发 Wi-Fi + 充电」发热明显，触发降频后表现为「越用越慢」。

详见主 README 的「它解决什么问题」与 `docs/DESIGN.md`。
